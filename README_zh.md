从 AWS 基础、存储和权限开始，掌握网络、云主机和数据库，再通过 Web 与 Serverless 项目串联所学。逐步学习安全、监控、消息与工作流、自动化部署，并按需要探索 DNS/CDN、容器、共享存储、缓存、数据分析和 AI。先做引导实验，再完成独立挑战，全程练习故障排查和资源清理。配合所选考试的考纲，也可通过这些动手实践巩固 AWS 认证备考知识。
